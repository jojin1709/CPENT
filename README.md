## About

CPENT Study Guide is a comprehensive, interactive web application designed to help aspiring penetration testers prepare for the **EC-Council Certified Penetration Testing Engineer (CPENT)** certification exam.

This single-page application covers all **13 modules**, **5 exam zones**, hands-on labs, cheat sheets, tools, resources, and a complete exam day guide — all in one beautiful, animated interface.

## Exam Information

### CPENT Certification Levels

| Score | Certification |
|-------|---------------|
| **70%+** | CPENT (Certified Penetration Testing Professional) |
| **90%+** | LPT Master (Licensed Penetration Tester Master) |

### Exam Format

- **Duration:** 24 hours (single session) or 2 x 12 hours
- **Format:** 100% hands-on, remotely proctored
- **Environment:** Kali Linux / Parrot Security OS
- **Report:** Required within 30 days

### Exam Zones

1. **Active Directory** — Enterprise AD forest exploitation
2. **Binaries** — Reverse engineering and exploit development
3. **IoT** — Firmware analysis and IoT device exploitation
4. **Web Applications** — OWASP Top 10 and server exploitation
5. **CTF Challenges** — Linux/web misconfigs and pivoting
